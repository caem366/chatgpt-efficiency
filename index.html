Introduction

This project represents the convergence of modern web design principles and artificial intelligence evaluation methodologies. The primary objective is to develop a comprehensive web-based platform that not only demonstrates proficiency in contemporary web technologies but also serves as a research tool for evaluating the efficiency and performance of ChatGPT across diverse question domains. By integrating MongoDB for robust data management, Node.js for server-side processing, and the ChatGPT API for natural language processing capabilities, this project creates a unique framework for assessing AI response quality, accuracy, and efficiency. The web interface provides an intuitive and visually appealing platform to present research findings, while the backend infrastructure enables systematic data collection and analysis. This dual-purpose approach allows for both the demonstration of full-stack web development skills and the generation of meaningful insights into ChatGPT's performance characteristics across different subject areas including History, Social Science, and Computer Security.

Research

Research Approach

Tools and Technologies:

  • MongoDB: Utilized as the primary database solution for storing questions, ChatGPT responses, evaluation metrics, and performance data. MongoDB's flexible document-based structure allows for efficient storage of varying response formats and metadata.
  • Node.js: Serves as the backend runtime environment, handling API requests, managing database connections, processing data, and orchestrating the communication between the ChatGPT API and the MongoDB database. Express.js framework is employed for routing and middleware management.
  • ChatGPT API: Integrated to generate responses to questions across multiple domains. The API is configured to track response times, token usage, and quality metrics for comprehensive efficiency analysis.
  • Frontend Technologies: HTML5, CSS3, and JavaScript create an interactive and responsive user interface for displaying evaluation results and charts.

The methodology involves systematic querying of ChatGPT across different subject domains, collecting response data, analyzing performance metrics including response time, accuracy, and coherence, and visualizing the findings through interactive charts and graphs.

📊

Dataset

Dataset Overview

The evaluation dataset comprises carefully curated questions across three distinct academic domains, each chosen to test different aspects of ChatGPT's knowledge and reasoning capabilities:

  • History: Questions covering various historical periods, events, figures, and civilizations. This domain tests ChatGPT's ability to recall factual information, understand temporal relationships, and analyze historical contexts. Sample topics include ancient civilizations, world wars, political movements, and cultural developments.
  • Social Science: Questions encompassing psychology, sociology, economics, and anthropology. This domain evaluates ChatGPT's understanding of human behavior, social structures, economic principles, and cultural phenomena. Topics include social theories, psychological concepts, economic models, and demographic trends.
  • Computer Security: Technical questions related to cybersecurity, encryption, network security, and threat analysis. This domain assesses ChatGPT's proficiency with technical concepts, its ability to explain complex security protocols, and provide practical security recommendations. Topics include cryptography, malware analysis, network protocols, and security best practices.

Each domain contains approximately 50-100 questions of varying complexity levels, ranging from basic recall to advanced analytical queries, ensuring a comprehensive evaluation of ChatGPT's capabilities.

⚙️ Technical Breakdown

MongoDB Schema Design

Database: ChatGPT_Evaluation

  • Collections:
    • History - Historical knowledge questions
    • Social_Science - Sociology domain questions
    • Computer_Security - Technical security questions
    • results - Evaluation results and metrics
  • Question Schema: domain, question, choices[], correctAnswer, processed status, timestamps
  • Results Schema: questionId, chatgptResponse, extractedAnswer, isCorrect, responseTime, tokens, model, domain

Node.js API Routes

  • POST /api/populate - Parses CSV files and populates MongoDB collections
  • POST /api/evaluate - Triggers multi-model evaluation (5 GPT models), returns immediately while processing continues
  • GET /api/results - Retrieves evaluation metrics with domain/model breakdowns
  • GET /api/status - Returns database connection and question processing status
  • Middleware Stack: CORS, Express JSON parser, Static file serving, Custom validation middleware

ChatGPT API Integration Flow

  1. Request Formation: Format question with multiple choice options, send to OpenAI Chat Completions API
  2. Model Processing: 5 models evaluated in parallel (gpt-3.5-turbo, gpt-4, gpt-4-turbo-preview, gpt-4o, gpt-4o-mini)
  3. Response Parsing: Extract answer letter (A/B/C/D) using regex patterns, measure response time and token usage
  4. Result Storage: Store in MongoDB with correctness validation, domain categorization, and performance metrics
  5. WebSocket Broadcasting: Real-time progress updates sent to all connected clients showing question X/150 processed
  6. Metrics Calculation: Aggregate accuracy, response times, token usage by domain and model for comprehensive analysis

Experience & Learning

  • Technical Growth: Developed expertise in full-stack development integrating MongoDB, Node.js, Express, and OpenAI API with real-time WebSocket communication
  • Design Evolution: Transitioned from traditional UI to modern minimal monochrome design with glassmorphism, improving user experience and visual appeal
  • Problem Solving: Resolved critical bug where subsequent models showed "All questions already evaluated" despite not being processed, by replacing boolean processed flag with model-specific result tracking using composite keys (questionId + model)
  • Data Analysis: Gained insights into LLM performance variations across domains, discovering that newer models (GPT-4o) achieve 93.26% accuracy while older models prioritize speed

Proposed Improvements

  • Enhanced Analytics: Add confusion matrix visualization, per-question difficulty analysis, and detailed error pattern identification
  • User Features: Implement user authentication, custom question set uploads, and personalized evaluation reports
  • Comparative Analysis: Add support for evaluating other LLMs (Claude, Gemini, Llama) for cross-platform performance comparison

Key Takeaway: This project demonstrates the practical application of modern web technologies to evaluate AI systems, combining theoretical knowledge with hands-on implementation to create a professional, production-ready evaluation platform that provides valuable insights into ChatGPT's performance across diverse knowledge domains.
